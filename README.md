## 💼 Featured Project

### 📦 StockFlow: ERP + HRMS Suite
**ASP.NET Core Web API · React · Redux Toolkit · SQL Server · JWT · ADO.NET · Groq LLM**

A full-stack business management platform: an **ERP** for trading and distribution businesses and an **HRMS** for people operations, secured with **JWT authentication and four role-based access levels** (Admin, Staff, HR, Employee).

| | ERP Module | HRMS Module |
|---|---|---|
| **Core** | Products, Customers, Suppliers | Employees, Departments, Designations |
| **Operations** | Purchase Orders, Sales Orders | Attendance, Leave Management |
| **Finance** | Customer and Supplier Payments, Dues | Payroll and Payslip Generation |
| **Insights** | Dashboard, Inventory, Stock Movements | HR Dashboard, Employee Self-Service |

**Engineering highlights**
- 🔐 **JWT authentication** with `[Authorize(Roles)]` on every API, plus **protected routes and role-based sidebar** in React
- 🔑 **bcrypt** password hashing, Axios **request/response interceptors** for token injection and 401/403 handling
- 🧾 **ACID transactions**: purchase order receipt updates the order status, stock quantity and stock ledger atomically
- 🗄️ **19-table SQL Server schema** with **stored procedures** (leave rules, payroll generation, HR dashboard), **views** and **triggers** (salary-change history, approved leave to attendance)
- 🧩 **Dependency Injection** with `IConfiguration` in ASP.NET Core controllers, **parameterized queries** against SQL injection
- 🧠 **AI assistant**: common business questions are answered directly from the database, other questions go to an **LLM**, and a graceful fallback keeps the app working when the AI service is unavailable
- ♻️ **Redux Toolkit** slice per page, responsive dark-green UI with a consistent design system

`ASP.NET Core` `JWT` `Redux Toolkit` `SQL Server` `Stored Procedures` `Triggers` `Views` `Transactions` `REST API`
